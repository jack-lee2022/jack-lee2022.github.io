最近由於被一般手持式三用電表的資料擷取(RS232) 的速度慢與錯誤率高所苦，所以便跟XX借了USB4065來測試，

USB 4065是DMM系列中低價位的 6 位半多功能數位電表( **硬體小計：** **TWD 49,900**)

在使用之前須了解規格與下載驅動程式，

規格敘述: <https://sine.ni.com/nips/cds/view/p/lang/zht/nid/204061>

驅動軟體下載 : NI-DMM 3.0.2 - Windows 2000/7 64 bit/XP/Vista x64/Vista x86/7 x86

<https://joule.ni.com/nidu/cds/view/p/id/1622/lang/zht>

 1. 安裝驅動程式: UNZIP DMM302-->DMM302資料夾選AUTORUN.exe

選擇Install NI-DMM 3.0.3

|  |
| --- |
|  |
|  |

選擇自己電腦中安裝的LabVIEW版本，按NEXT完成安裝步驟，
