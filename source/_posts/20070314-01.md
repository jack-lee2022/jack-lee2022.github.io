今天想用PXI 1411來接CCD擷取圖案時,  
發現少灌了IMAQ程式,  
所以就放了原先的NI驅動程式的光碟,  
灌好後卻發現奇怪的現象,  
我只能在ＭＡＸ操作PXI1411, 在Labview中卻看不到VI(如Grab.vi, Snap.vi)  
後來我又灌了Vision Acquisition Software,  
我在LabVIEW8的環境找的到IMAQ的VI,  
但是在LabVIEW8.2的環境卻找不到,  
一陣慌亂, 最後上網找到IMAQ的版本資料：  

NI-IMAQ:

|  |  |
| --- | --- |
| NI-IMAQ Version | LabVIEW Version |
| 2.5 | 6.0, 5.1 |
| 2.5.1 | 6.0, 5.1 |
| 2.6 | 7.0, 6.1, 6.0 |
| 2.6.1 | 7.0, 6.1, 6.0 |
| 3.0 | 7.1, 7.0, 6.1 |
| 3.0.1 | 7.1, 7.0, 6.1 |
| 3.1 | 7.1, 7.0, 6.1 |
| 3.1.1 | 7.1, 7.0, 6.1 |
| 3.3.1 | 7.1, 7.0, 6.1 |
| 3.5.1 | 8.20, 8.0, 7.1, 7.0 |

NI-IMAQ for IEEE 1394:

|  |  |
| --- | --- |
| NI-IMAQ for IEEE 1394 Version | LabVIEW Version |

| 1.1 | 6.1, 6.0, 5.1 |

| 2.0.1 | 7.1, 7.0 |
| 2.5.1 | 8.2, 8.0, 7.1, 7.0 |

不過還沒找到IMAQ在幾版之後被併入Vision Acquisition Software,  
最後我是找到Vision 8.2.1 Acquisition Software, 安裝IMQ3.7,  
在選擇安裝項目時, Labview8.2及Labview8.0 support 都要勾選安裝,  
  
![](/images/pixnet/20070314-01/05df9fa4f60b.jpg)  
  
然後就可以同時在LabVIEW8及8.2上開發IMAQ的程式,  
  
![](/images/pixnet/20070314-01/9584d5f11cb8.jpg)  
  
所以在不同的LabVIEW版本上安裝IMAQ驅動程式要特別注意一下
