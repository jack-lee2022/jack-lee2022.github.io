這篇是介紹如何自己製作一個PCB元件，  
任何在電路圖上的元件都有自己對應的PCB元件，  
這是為了PCB Layout使用，  
PCB元件的製作有兩種方法，  
一是完全自己畫，二是使用component Wizard,  
  
這裡介紹的是第二種，  
  
軟體 : Protel99SE  
  
步驟 :  
  
1. 開啟Protel99SE, 新增一個Design, 在document資料夾中新增一個PCB文件，  
    開啟PCB文件，在Tool-->New Component  

|  |
| --- |
|  |
| 寄件者 [pcb component](https://picasaweb.google.com/labview.net/PcbComponent?authkey=N-0tch6nJ_s) |

  
  
2. Component Wizard出現，按Next,  
[![](https://lh4.ggpht.com/labview.net/SLwJKVOuKYI/AAAAAAAAAtU/_HaRpCn4VDw/s800/002.JPG)](https://picasaweb.google.com/labview.net/PcbComponent/photo?authkey=N-0tch6nJ_s#5241074139454646658)  
  
3. Component Wizard提供許多封裝格式，如DIP、SOP、電阻與電容等等，這裡我選擇SOP做一個介紹，這視窗的最底下可以選擇元件是要以英制或公制來顯示，  
[![](https://lh3.ggpht.com/labview.net/SLwJKp5koWI/AAAAAAAAAtc/mwQ48ZLhOiI/s800/003.JPG)](https://picasaweb.google.com/labview.net/PcbComponent/photo?authkey=N-0tch6nJ_s#5241074145003086178)
