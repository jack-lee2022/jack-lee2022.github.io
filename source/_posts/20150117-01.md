為了要寫servo的程式，我很好奇地去找了LabVIEW for Arduino的Toolkit，

原先以為是找不到了，不過後來卻發現可以從LabVIEW提供的VI Package Manager下載，

<https://jki.net/vipm/download>

下載與安裝步驟如下:

首先在VI Package Manager中搜尋Arduino，即可找LabVIEW for Arduino tool kit，

![lvardu001.png](/images/pixnet/20150117-01/05aa2dbdfd0c.png "lvardu001.png")

  選擇Install

![lvardu003.jpg](/images/pixnet/20150117-01/65ac9b2f38b4.jpg "lvardu003.jpg")

安裝完畢

![lvardu004.jpg](/images/pixnet/20150117-01/04e6833e6716.jpg "lvardu004.jpg")

到C:\Program Files\National Instruments\LabVIEW 2012\vi.lib\LabVIEW Interface for Arduino\Firmware\LIFA\_Base

找到LIFA\_Base.ino upload韌體到Arduino PCB板上，

![lvardu005.jpg](/images/pixnet/20150117-01/67c59427b2c3.jpg "lvardu005.jpg")

然後到C:\Program Files\National Instruments\LabVIEW 2012\vi.lib\LabVIEW Interface for Arduino)

執行LabVIEW Interface for Arduino.lvlib

![lvardu006.jpg](/images/pixnet/20150117-01/e91b6f68c331.jpg "lvardu006.jpg")

LabVIEW Interface for Arduino.lvlib提供許多的範例可以練習使用LabVIEW來與Arduino作溝通。

![lvardu007.jpg](/images/pixnet/20150117-01/8aed9adf4272.jpg "lvardu007.jpg")
