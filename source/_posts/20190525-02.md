想在Windows下開發Django應用程式，需要安裝:

* Python
* virtualenv
* Django

### 1. Python下載與安裝:

選 [Python 3.7.3](https://www.python.org/downloads/release/python-373/) 下載

安裝時請注意以下幾點：

* 請注意安裝路徑, 他預設是在"使用者"目錄下面, 最好換到非中文目錄底下。
* 安裝時選 customize install, 這樣才可以自選安裝路徑。

#### 安裝 pip

如果是安裝 python 3.5 以上的, 都會預設安裝 pip, 所以只要更新 pip 即可,

#### 關於 pip 與 pip3 的差異

pip 和 pip3 都在 Python36\Scripts\ 目錄下, 如果同時裝有python2 和 python3, pip 默認給 python2 用, pip3 指定給 python3 用, 如果只裝有 python3，則pip和pip3是等價的, 安裝了python3之後，就會有pip3。

### 2. Django安裝

在安装 Django 前，系统需要已经安装了Python的开发环境。

Django 下载地址：<https://www.djangoproject.com/download/>

**注意：**目前 Django 1.6.x 以上版本已经完全兼容 Python 3.x。

執行命令提示字元，輸入:

`pip3 install Django==2.2`
