程式(C或組語)在寫完後經過Build，會產生HEX檔。

HEX檔可以直接拿來燒錄，

用在大量生產時，你需要拿程式給晶片燒錄商，但又不想程式碼內容被對方看到，

首先在MPLAB開一個新的PROJECT，

然後選擇Device型號，

[![](https://lh3.googleusercontent.com/_AMuZNDyhqSY/Ta3CHN-dsdI/AAAAAAAABSQ/2UexRrf0iSE/s400/hex001.JPG)](https://picasaweb.google.com/lh/photo/BJSQTasIY3CAOOPdpxhn_2xBLyvpFC9f9kHR8sRy4ik?feat=embedwebsite)

接著File--> Import，import Hex檔，

[![](https://lh4.googleusercontent.com/_AMuZNDyhqSY/Ta3CHUm5PNI/AAAAAAAABSU/O6YOi8GzLLU/s400/hex002.JPG)](https://picasaweb.google.com/lh/photo/G18KhjlYBIAWpKmuLtqpK2xBLyvpFC9f9kHR8sRy4ik?feat=embedwebsite)

 找到.HEX檔，按開啟，

[![](https://lh5.googleusercontent.com/_AMuZNDyhqSY/Ta3CHL8LbhI/AAAAAAAABSM/BWijTAT1t64/s400/hex003.JPG)](https://picasaweb.google.com/lh/photo/Szs-ell-Tt4YBl3F3QFtZGxBLyvpFC9f9kHR8sRy4ik?feat=embedwebsite)

到View-->Program Memory

[![](https://lh5.googleusercontent.com/_AMuZNDyhqSY/Ta3CHv7tlUI/AAAAAAAABSY/5QsunJWofVE/s400/hex004.JPG)](https://picasaweb.google.com/lh/photo/ktl65ogCzZ-SZI7oBzi9bmxBLyvpFC9f9kHR8sRy4ik?feat=embedwebsite)

可以看到 Program Memory 已經有code存在，

[![](https://lh6.googleusercontent.com/_AMuZNDyhqSY/Ta3CH0FVc9I/AAAAAAAABSg/H78qFzRXe9s/s400/hex005.JPG)](https://picasaweb.google.com/lh/photo/ZVYuJPlygIaA9Xgz49xs1mxBLyvpFC9f9kHR8sRy4ik?feat=embedwebsite)

如果看一下config bits的話，也會發現設定值 (一般是希望在程式碼當中用#programa config來設定)

[![](https://lh4.googleusercontent.com/_AMuZNDyhqSY/Ta3CH647QEI/AAAAAAAABSc/hhzTGYmGlKM/s400/hex006.JPG)](https://picasaweb.google.com/lh/photo/BT1KHSWykRbd_3pixeKD_mxBLyvpFC9f9kHR8sRy4ik?feat=embedwebsite)

最後用programmer進行燒錄即可。
