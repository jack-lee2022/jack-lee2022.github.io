從去年想要寫Android的App開始研究其開發環境的安裝，

現在，安裝的過程顯得簡單的多，

除了原先要安裝JDK ( Java Development Kit )外

(<https://www.oracle.com/technetwork/java/javase/downloads/jdk8-downloads-2133151.html>)，

只要再安裝一個軟體即可，

這歸功於ADT Bundle 的出現，下載的官方網址為:

(<https://developer.android.com/sdk/index.html>)

ADT Bundle包含了:

* Eclipse + ADT plugin
* Android SDK Tools
* Android Platform-tools
* A version of the Android platform
* A version of the Android system image for the emulator

下載解壓縮後，可以看到eclipse和sdk資料夾，以及SDK Manager執行檔，

![install 001.jpg](/images/pixnet/20141005-01/7ff9d249d2db.jpg "install 001.jpg")

進入eclipse資料夾，點選eclipse應用程式，

![install 002.jpg](/images/pixnet/20141005-01/6a31f3d31a36.jpg "install 002.jpg")

eclipse程式啟動的模樣，

![install 003.jpg](/images/pixnet/20141005-01/b042c3e911e3.jpg "install 003.jpg")

首先，到Window-->Android SDK Manager

![install 004.jpg](/images/pixnet/20141005-01/f92d412f5285.jpg "install 004.jpg")

根據你所需要的Android版本下載其SDK package,

![install 005.jpg](/images/pixnet/20141005-01/76c9df793529.jpg "install 005.jpg")

安裝完成後即可準備開始Android的專案建立。
