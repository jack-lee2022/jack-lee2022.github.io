本篇介紹使用Pycharm開發Python程式與用Matplotlib套件繪圖。  
  
1. 建立新專案並新增python檔案matplot.py  
  
2. 在Pycharm中安裝matplotlib套件，打開File-->Setting，找到Project Interpreter，點“+”添加   
[![](https://1.bp.blogspot.com/-DxW01fnvSU0/XSF9zj-MrFI/AAAAAAAAO_c/IOVVvWhJJ3gBAe03Dj-mu5LMDMQTVIPVgCLcBGAs/s400/plt01.jpg)](https://1.bp.blogspot.com/-DxW01fnvSU0/XSF9zj-MrFI/AAAAAAAAO_c/IOVVvWhJJ3gBAe03Dj-mu5LMDMQTVIPVgCLcBGAs/s1600/plt01.jpg)  
  
搜尋matplotlib後，安裝該套件。  
[![](https://1.bp.blogspot.com/-dGqZPvGfzy0/XSF9zm2qx5I/AAAAAAAAO_U/xRCBCpySehAuP-Zxo2ftxNYf2KQIxTyZACLcBGAs/s400/plt02.jpg)](https://1.bp.blogspot.com/-dGqZPvGfzy0/XSF9zm2qx5I/AAAAAAAAO_U/xRCBCpySehAuP-Zxo2ftxNYf2KQIxTyZACLcBGAs/s1600/plt02.jpg)  
  
  
3. 加入程式碼:

```python
from matplotlib import pyplot as plt
import numpy as np

x = np.linspace(1, 10, 20)
print(x)
y = 3 * x + 2fig = plt.figure()
axes = fig.add_axes([0.1, 0.1, 0.9, 0.9])
axes.plot(x, y, 'r')

plt.show()
```

[![](https://1.bp.blogspot.com/-sfIXgtGy-CM/XSF9zvnCHYI/AAAAAAAAO_Y/d4wS03zZIQYnwBtKDM06g7qSdtM_dE-4gCLcBGAs/s400/plt03.jpg)](https://1.bp.blogspot.com/-sfIXgtGy-CM/XSF9zvnCHYI/AAAAAAAAO_Y/d4wS03zZIQYnwBtKDM06g7qSdtM_dE-4gCLcBGAs/s1600/plt03.jpg)  
  
其中  
(1) linspace的用法為:   
       numpy.linspace(start, stop, num=50, endpoint=True, retstep=False, dtype=None)  
         
      np.linspace(1,10,20)   
      #表示在1與10之間分20個點。 

(2) add\_axes: 新增子區域     fig.add\_axes(0.1,0.1,0.9,0.9)     #figure的百分比,從figure 10%的位置開始繪製, 寬高是figure的90%

5. 讓matplotlib繪圖變成浮在開發環境上，意思是讓figure浮窗  
選擇File--->Settings--->Tools--->Python Scientific"  
取消勾選Show plots in tool window
