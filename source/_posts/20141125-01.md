最近因為要用LabVIEW抓Webcam的影像，

安裝了Vision Module和Vision Acquistion Software，發現有兩個Driver: IMAQ與IMAQdx，

好奇之下查的一下這兩個由甚麼不同?

參考網頁: <https://digital.ni.com/public.nsf/allkb/0564022DAFF513D2862579490057D42E>

1. The **NI-IMAQ** driver software supports National Instruments hardware only and is needed to use the following image acquisition devices:

簡單的說NI-IMAQ是支援NI開發的硬體的 Driver，適合的硬體如下:

* National Instruments Camera Link Frame Grabbers
* National Instruments Parallel Digital Frame Grabbers
* National Instruments Analog Frame Grabbers
* National Instruments 17xx Smart Cameras

2. The **NI-IMAQdx** driver software is needed to use third-party image acquisition devices which use the following buses and standards:

而NI-IMAQdx是支援使用第三方影像擷取裝飾的Driver，響螢幕上的Camera或是WebCAM都屬於這一類，

* Gigabit Ethernet Cameras Supporting GigE Vision
* FireWire IEEE 1394 Cameras
* USB 2.0 Cameras Supporting Microsoft DirectShow
* USB 3.0 Cameras Supporting USB3 Vision

3. The **NI-IMAQ I/O** driver software is a smaller driver API used exclusively to program the National Instruments Vision RIO image acquisition cards including the following cards:

NI-IMAQ I/O是支援NI的視覺RIO影像擷取卡的Driver

* NI PCIe-8255R
* NI PCI-8254R
* NI PCIe-8237R
