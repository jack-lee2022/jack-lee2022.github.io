要在VS Code中安裝 **Claude Code for VS Code** 官方擴充功能，請按照以下步驟操作。這款工具結合了 VS Code 的圖形介面與 Anthropic 強大的 CLI 自動化能力。

### 第一步：從擴充功能商店安裝

1. 開啟 VS Code。
2. 點擊左側活動列的 **Extensions (擴充功能)** 圖示（或按 `Ctrl + Shift + X`）。
3. 在搜尋框輸入 **「Claude Code for VS Code」**。
4. 找到由 **Anthropic** 官方發佈的項目（如你截圖所示），點擊 **Install**。

![](/images/blogger/20260418-02/aa3977031fbc.png)

  

---

### 第二步：安裝必要的 CLI 本體

這款擴充功能需要搭配 Anthropic 的命令列工具（CLI）才能運作。請在 VS Code 內建終端機（`Ctrl + ~`）執行以下指令：

* **Windows (PowerShell):**

  ```powershell
  irm https://claude.ai/install.ps1 | iex
  ```
* **macOS / Linux:**

  ```bash
  curl -fsSL https://claude.ai/install.sh | bash
  ```

---

### 第三步：登入授權（關鍵步驟）

安裝完擴充功能與 CLI 後，你需要讓它連結到你的帳戶：

1. 在終端機輸入 `claude` 並按回車。
2. 系統會跳出一個驗證碼並詢問是否開啟瀏覽器。
3. 在瀏覽器登入你的 Claude 帳戶完成授權。

   * *註：你需要有 Claude Pro 訂閱或 API Console 的點數。*

---

### 第四步：啟動擴充功能介面

授權完成後，你可以透過以下方式使用圖形介面：

1. **側邊欄圖示：** 點擊 VS Code 最左側新出現的 **「放射狀圓圈」** 圖示（截圖中的橘色 Logo）。
2. **命令面板：** 按下 `Ctrl + Shift + P`，輸入 `Claude Code: Open Chat`。
3. **右下角狀態列：** 點擊 VS Code 視窗右下角的 `✱ Claude` 字樣。

![](/images/blogger/20260418-02/5cd0c0efebaa.png)

---

### 第五步：專案初始化 (選用但強烈建議)

進入對話介面後，建議輸入指令：

```bash
/init
```

這會建立 `CLAUDE.md`，你可以將之前在 R&D 專案中使用的開發規範（例如 ESP32 的編譯環境或 軟體的 API 規範）寫進去，讓 Claude 之後能更準確地協助你。

---

### ⚠️ 常見問題：安裝後沒反應？

* **環境變數：** 如果安裝了 CLI 卻在終端機找不到 `claude` 指令，請**重新啟動 VS Code**。
* **權限問題：** 若出現紅字報錯，請確認你是否以系統管理員權限執行 PowerShell（如之前處理 $HOME 的情況）。
