根據目前的開發者社群資訊，這款 AI coding agent 在終端機工具（CLI）上的正式名稱通常是 **`opencode-ai`** 或 **`open-code`**。

請嘗試以下正確的安裝步驟：

---

### 1. 嘗試正確的套件名稱

請在您的命令提示字元（CMD）中輸入以下指令：

```bash
npm install -g opencode-ai
```

或者（如果是另一個常見分支）：

```bash
npm install -g open-code
```

---

![](/images/blogger/20260216-01/1bde7a09cc98.png)

**驗證安裝**：在終端機輸入 `opencode`，若能成功啟動並進入配置頁面，即代表安裝成功。

![](/images/blogger/20260216-01/3e067c1a1a8b.png)

  

利用Ctrl+P 指令來選擇Opencode提供的AI模型

![](/images/blogger/20260216-01/e3bf2ab98bea.png)

來源中提到的啟動命令為 `opencode`，這可能是該插件特定的命令名稱。此外，OpenCode 內置了許多**免費模型**（如 Gemini 1.5 Pro 的替代方案等），您可以通過輸入 `/models` 來查看並選擇標註為 `free` 的模型直接開始編程。
