QT4的Designer顯然是與QT3有很大的不同，  
在參考許多文章後才將QT4的ui檔，轉換成exe檔，  
  
所使用的軟體為QT4.4.0，  
  
步驟如下：  
  
1. 開啟QT Designer，建立一個widget專案，拉一個PushButton放置在表單上，並將text屬性填入"hello"，  
  
[![](https://lh3.ggpht.com/labview.net/SHhn9u1QtQI/AAAAAAAAAoc/WMAsiGFG9CU/s800/001.JPG)](https://picasaweb.google.com/labview.net/Qt4Ui/photo?authkey=BnGDJQUyVYI#5222038078177195266)  
  
2. 存檔成qtui1.ui，同時到表單-->檢試程式碼將源碼儲存，預設的檔名是ui\_qtui1.h，  
[![](https://lh4.ggpht.com/labview.net/SHhn9i05_cI/AAAAAAAAAok/-4JNs-gSSP0/s800/002.JPG)](https://picasaweb.google.com/labview.net/Qt4Ui/photo?authkey=BnGDJQUyVYI#5222038074954481090)  
  
3. 將這兩個檔案放入C槽新增的qtui1資料夾中，這時需要一個main.cpp(請參考QT Designer Manual的Using a Component in Your Application部份)  
  
main.cpp的內容為：

```cpp
#include "ui_qtui1.h"
 int main(int argc, char *argv[])
 {
     QApplication app(argc, argv);
     QWidget *widget = new QWidget;
     Ui::Form ui;
     ui.setupUi(widget);
```

     widget->show();  
     return app.exec();  
 }  
  
4. 新增一個qtui.pro檔，內容為：  
 TEMPLATE    = app  
 FORMS       = qtui1.ui  
 SOURCES     = main.cpp  
  
  
5. 啟動QT4.4.0 Command Prompt，  
用 cd :c\qtui1進入qtui1資料夾中，  
用qmake -o Makefile =>生成Makefile文件，  
再用nmake =>執行Makefile中的命令，會在dedug資料夾生成一個qtui1.exe  
  
[![](https://lh5.ggpht.com/labview.net/SHhn9heawbI/AAAAAAAAAos/l22hQrgcw4I/s800/003.JPG)](https://picasaweb.google.com/labview.net/Qt4Ui/photo?authkey=BnGDJQUyVYI#5222038074591723954)  
  
6. 接著cd debug，然後輸入qtui1，即可執行qtui1.exe  
  
[![](https://lh4.ggpht.com/labview.net/SHhn90VotNI/AAAAAAAAAo0/V6S35O0mS0g/s800/004.JPG)](https://picasaweb.google.com/labview.net/Qt4Ui/photo?authkey=BnGDJQUyVYI#5222038079655163090)
