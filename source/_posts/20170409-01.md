由於網路上有很多寫好的Arduino函式庫，大部分都是用成ZIP下載，

我查了一些關於如何撰寫的資料，如果有興趣可以試著寫看看:

1. <https://yehnan.blogspot.tw/2013/01/arduino.html>

2. Arduino Style Guide for Writing Libraries <https://www.arduino.cc/en/Reference/APIStyleGuide>

3. Writing a Library for Arduino <https://www.arduino.cc/en/Hacking/LibraryTutorial>

4. How to write libraries for the Arduino? <https://playground.arduino.cc/Code/Library>

這一篇是簡單的筆記，說明如何將網路上下載的函示庫與範例輸入到Arduino的函示庫中，

Step 1. 在草稿碼-->Include Library --> Add .ZIP Library...

![lib_input001.jpg](/images/pixnet/20170409-01/7093fb39dbe1.jpg "lib_input001.jpg")

Step 2. 選擇想要輸入的函示庫資料夾或ZIP

![lib_input002.jpg](/images/pixnet/20170409-01/29adcf90298c.jpg "lib_input002.jpg")

Step 3. 在檔案-->範例中即可找到之前輸入的函示庫與範例。

![lib_input003.jpg](/images/pixnet/20170409-01/da4b129532c1.jpg "lib_input003.jpg")
