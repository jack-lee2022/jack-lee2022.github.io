# 在 Hermes Agent 中安裝 n8n Skills 與 MCP 完整教學

這篇教學會帶你完成以下事項：

* 了解 Hermes Agent 的 **Skills** 與 **MCP** 分別是什麼
* 如何在 Hermes 中安裝 n8n 相關 Skills
* 如何在 Hermes 中接上 n8n 的 MCP Server
* 安裝完成後的測試與排錯方法

![](/images/blogger/20261105-02/8515ea1af8af.png)

本文適合已經裝好 Hermes Agent 且想讓 Hermes 能夠操控 n8n 的使用者。

## 一、Skills 與 MCP 是什麼？

### 1.1 Hermes Skills

Skills 是 Hermes Agent 的**可重用知識包**。當 Hermes 學會了某個工作流程（例如如何部署 n8n、如何寫 n8n expression），就會把這些經驗寫進 Skill 檔案。下次遇到相同任務時，Hermes 會自動加載這些 Skill，不需要重新說明。

舉例：

* `n8n-self-hosting` — 自訂部署 n8n 的完整流程
* `n8n-workflow-patterns` — 常見 workflow 架構設計模式
* `n8n-code-javascript` / `n8n-code-python` — 在 n8n Code Node 中寫 JS/Python
* `n8n-error-handling` — 排錯和錯誤處理

### 1.2 MCP（Model Context Protocol）

MCP 是 Anthropic 推出的開放協議，讓 LLM 可以通過標準化方式連接外部工具。在 Hermes 中，MCP 服務可以提供額外的工具給 Hermes 使用，例如操控 n8n 、查詢資料庫、控制檢視器。

簡單說：

* **Skills** = Hermes 腦袋裡的知識
* **MCP** = Hermes 可以呼叫的外掛工具

**建議**：如果你主要想讓 Hermes 幫你"設計 n8n workflow"或"排錯 n8n"，先裝 Skills；如果想讓 Hermes "直接執行 n8n workflow"或"提取 n8n 資料"，就接 MCP。

## 二、安裝前準備

在開始之前，請確認：

* 你已經安裝 [Hermes Agent](https://hermes-agent.nousresearch.com/docs) 且可以執行 `hermes` 指令
* 你有一個可用的 n8n 實例（自訂或 n8n Cloud）
* 你知道 n8n 的 API Key 或是 MCP Server 連線資訊

檢查 Hermes 版本：

```
hermes --version
```

建議先更新到最新版：

```
hermes update
```

## 三、安裝 n8n Skills

### 3.1 檢視可用的 n8n Skills

Hermes 內建了一個 Skills Hub，可以直接搜索：

```bash
# 搜索所有 n8n 相關 skills
hermes skills search n8n

# 浏覽全部可用 skills
hermes skills browse
```

你會看到類似這樣的列表：

```
n8n-self-hosting        部署 n8n 到自己的伺服器
n8n-workflow-patterns   常見 workflow 設計模式
n8n-expression-syntax   n8n expression 語法與常見錯誤
n8n-code-javascript     在 Code Node 中寫 JavaScript
n8n-code-python         在 Code Node 中寫 Python
n8n-error-handling      錯誤處理與排錯
n8n-mcp-tools-expert    使用 n8n 的 MCP 工具
using-n8n-mcp-skills    如何在 Hermes 中使用 n8n MCP Skills
```

**n8n Skills 來源**：這些 n8n skills 是 **Hermes Agent 內建捆綁**的，隨 Hermes 安裝時從主程式碼庫複製到 `~/.hermes/skills/`。

* Hermes Agent 主程式碼庫：<https://github.com/NousResearch/hermes-agent>
* Bundled Skills Catalog：<https://github.com/NousResearch/hermes-agent/blob/main/website/docs/reference/skills-catalog.md>
* Optional Skills Catalog：<https://github.com/NousResearch/hermes-agent/blob/main/website/docs/reference/optional-skills-catalog.md>
* 社群整合版（把 7 個 skills 合併成一個 master skill）：<https://github.com/spfcraze/Hermes-n8n-skills>

### 3.2 安裝單一 Skill

使用 `hermes skills install` 安裝：

```bash
# 安裝 n8n 自訂部署教學
hermes skills install n8n-self-hosting

# 安裝 workflow 設計模式
hermes skills install n8n-workflow-patterns

# 安裝 n8n expression 語法
hermes skills install n8n-expression-syntax
```

### 3.3 一次安裝常用組合

如果你想讓 Hermes 完整支援 n8n 開發，建議安裝這組：

```
hermes skills install n8n-self-hosting
hermes skills install n8n-workflow-patterns
hermes skills install n8n-expression-syntax
hermes skills install n8n-code-javascript
hermes skills install n8n-code-python
hermes skills install n8n-error-handling
hermes skills install n8n-mcp-tools-expert
hermes skills install using-n8n-mcp-skills
```

### 3.4 確認安裝結果

```
hermes skills list
```

這個指令會顯示已安裝的 skills，你應該會看到剛剛裝的 n8n 相關項目。

**技巧**：在對話中可以用 `/skill n8n-self-hosting` 手動加載某個 skill，或者用 `hermes -s n8n-self-hosting` 在啟動時就加載。

## 四、接上 n8n 的 MCP Server

### 4.1 為什麼要接 MCP？

裝了 Skills 之後，Hermes 知道怎麼"說"關於 n8n 的事。但是如果要讓 Hermes 直接**執行**—例如啟動 workflow、查看 execution log、創建 credential—就需要通過 MCP 連接 n8n 的 API。

### 4.2 取得 n8n API Key

**步騟 1：**登入你的 n8n 網页。

**步騟 2：**點選左下角自己的頭像，選择 **Settings**。

**步騟 3：**在左側選單選擇 **N8N API**。

**步騟 4：**點擊 **Create an API key**，輸入名稱（例如 `Hermes`），然後複製生成的 API Key。

**步騟 5：**記下 n8n 的網址，例如 `https://n8n.example.com`。

**警告**：API Key 是敏感資訊，請不要貼在公開文章、GitHub 或聊天訊息中。只在 Hermes 的加密設定或 n8n UI 中使用。

### 4.3 使用 Hermes 接上 n8n MCP

Hermes 提供 `hermes mcp add` 指令來加入 MCP Server。以下是幾個實際可用的選擇：

#### 方案 A：npx 社群版 n8n-mcp（推薦，目前系統上使用的）

這是目前最常見的 n8n MCP Server，使用 npm 上的 `n8n-mcp` 套件：

* npm 套件頁面：<https://www.npmjs.com/package/n8n-mcp>
* GitHub 原始碼：<https://github.com/czlonkowski/n8n-mcp>

安裝範例（使用 npx，不需要手動安裝）：

```
hermes mcp add n8n \\
  --command "npx -y n8n-mcp" \\
  --env N8N_API_KEY="你的_API_KEY" \\
  --env N8N_API_URL="https://n8n.example.com"
```

**說明**：這個 n8n-mcp 是社群專案，由 Romuald Członkowski 維護，功能包含列出 workflow、執行 workflow、管理 credentials 等。

#### 方案 B：Hermes 官方 n8n MCP bridge（使用 Hermes catalog）

Hermes 官方的 MCP catalog 也有一個 n8n 條目，使用獨立的 bridge repo：

* Hermes catalog manifest：<https://github.com/NousResearch/hermes-agent/blob/main/optional-mcps/n8n/manifest.yaml>
* Bridge repo：<https://github.com/CyberSamuraiX/hermes-n8n-mcp>

安裝方式：

```
hermes mcp install official/n8n
```

它會自動複製 repo、建立虛擬環境，並提示你輸入 `N8N_BASE_URL` 和 `N8N_API_KEY`。

#### 方案 C：n8n 官方 Instance-level MCP Server（需要 n8n 開啟功能）

新版 n8n 支援 Instance-level MCP，可以直接讓 Hermes 透過 HTTP + OAuth 連線：

* 先在 n8n 中開啟 **Settings → Instance-level MCP**
* 複製 Server URL（結尾為 `/mcp-server/http`）
* 在 Hermes 中執行：

  ```
  hermes mcp install n8n-official
  ```
* 按提示貼上 Server URL，完成瀏覽器 OAuth 授權

詳細說明可參考 Hermes 官方 MCP 文件：<https://github.com/NousResearch/hermes-agent/blob/main/website/docs/user-guide/features/mcp.md>

#### 方案 D：自己寫一個簡單的 n8n MCP Server

如果上述方案都不符合需求，可以自己寫一個 Python 小程式：

```python
#!/usr/bin/env python3
import os
import requests
from mcp.server.fastmcp import FastMCP

N8N_HOST = os.environ["N8N_HOST"].rstrip("/")
N8N_API_KEY = os.environ["N8N_API_KEY"]

mcp = FastMCP("n8n")

headers = {
    "X-N8N-API-KEY": N8N_API_KEY
}

@mcp.tool()
def list_workflows() -> str:
    """列出所有 n8n workflows"""
    r = requests.get(f"{N8N_HOST}/api/v1/workflows", headers=headers, timeout=30)
    return r.text

@mcp.tool()
def get_workflow(workflow_id: str) -> str:
    """取得單一 workflow 資訊"""
    r = requests.get(f"{N8N_HOST}/api/v1/workflows/{workflow_id}", headers=headers, timeout=30)
    return r.text

@mcp.tool()
def execute_workflow(workflow_id: str) -> str:
    """手動執行 workflow"""
    r = requests.post(
        f"{N8N_HOST}/api/v1/workflows/{workflow_id}/execute",
        headers=headers,
        timeout=30
    )
    return r.text

if __name__ == "__main__":
    mcp.run()
```

將上述檔案存為 `~/n8n-mcp-server.py`，並裝必要套件：

```bash
pip install fastmcp requests
```

加入到 Hermes：

```
hermes mcp add n8n \
  --command "python3 /home/你的使用者/n8n-mcp-server.py" \
  --env N8N_API_KEY="你的_API_KEY" \
  --env N8N_HOST="https://n8n.example.com"
```

### 4.4 查看已接上的 MCP Server

```
hermes mcp list
```

顯示範例（使用 n8n-mcp 時）：

```
n8n  ✓  npx -y n8n-mcp
```

### 4.5 測試連線

```
hermes mcp test n8n
```

如果顯示成功，Hermes 就能在對話中使用 n8n 的工具。

## 五、在對話中使用 n8n Skills 與 MCP

### 5.1 使用 Skills 的例子

裝了 Skills 之後，你可以直接問 Hermes：

```
幫我寫一個 n8n workflow，每天早上 9 點從 Gmail 讀取信件並發送到 LINE。
```

Hermes 會自動使用 `n8n-workflow-patterns`、`n8n-expression-syntax` 等 skills 來設計 workflow，並用 `n8n-code-javascript` 寫出需要的 Code Node。

### 5.2 使用 MCP 的例子

接上 MCP 之後，你可以說：

```
幫我查看 n8n 裡面有哪些 workflow，然後啟動 "Somnics 每日庫存監控"。
```

Hermes 會通過 MCP Server 呼叫 `list_workflows` 和 `execute_workflow`，不需要你手動打開 n8n UI。

## 六、常見問題與排錯

| 問題 | 可能原因 | 解決方法 |
| --- | --- | --- |
| `hermes skills search n8n` 找不到東西 | Skills Hub 未連線或版本過舊 | `hermes update` 後再試 |
| Skill 裝了但沒生效 | 需要重新啟動 session | 輸入 `/reset` 或重新執行 `hermes` |
| `hermes mcp test n8n` 失敗 | API Key 錯誤或 n8n 網址不對 | 檢查 `N8N_API_KEY` 和 `N8N_HOST`，確認 n8n 可連線 |
| MCP Server 連上但沒有工具 | MCP Server 本身沒實作工具 | 換個 MCP Server 或自己實作 |
| Hermes 找不到 n8n 工具 | MCP 沒有加載 | 執行 `/reload-mcp` 或 `hermes mcp list` 確認 |

## 七、總結

* **Skills** 讓 Hermes 擁有 n8n 的專業知識，适合設計 workflow、排錯、寫 expression。
* **MCP** 讓 Hermes 能夠直接呼叫 n8n API，適合自動執行 workflow、查詢狀態。
* 安裝方式很簡單：`hermes skills install` 跟 `hermes mcp add`。
* 最常用的 n8n skills 包括 `n8n-self-hosting`、`n8n-workflow-patterns`、`n8n-expression-syntax`、`n8n-code-javascript`、`n8n-error-handling`。

裝好之後，你就可以在 Hermes 對話中直接指揮 n8n，無需一直切換到 n8n UI。

**推薦下一步**：試著讓 Hermes 幫你寫一個簡單的 n8n workflow，比如"每天寄一封網站健康檢查報告"，這樣可以同時測試 skills 和 MCP 的效果。
